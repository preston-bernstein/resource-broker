## CONTEXT.md
Glossary for the ollama-resource-broker repo. Key terms: Broker (the single program deciding GPU access), Contention (gaming/Plex claim on the GPU), Yield (whole-Broker state refusing inference while Contention present), Preemption (interrupting a running request for a higher-priority one, returns 503), Job (durable batch inference unit, SQLite-backed, survives restart), Queue (ordered durable line of Jobs), Park/Parked request (short-lived in-memory holding for Batch Synchronous requests during Yield), Fronting Proxy (entry point for Synchronous requests, speaks Ollama's API, forwards to real Ollama), Synchronous request (live, admitted-or-503, never saved), Embed lane (separate CPU-only lane fronting Infinity SigLIP, unrelated to this feature), Consumer (any service sending inference requests through the Broker — fashion-monitor, LightRAG, estate-scraper, one-off CLI jobs).
