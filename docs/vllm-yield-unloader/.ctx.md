## CONTEXT.md
Glossary for the resource-broker repo. Key terms: Broker (the single program deciding GPU access, avoid "Manager/Orchestrator/Gateway"), Contention (a high-priority claim on the GPU: gaming or Plex transcoding), Yield (the whole-Broker state that stops admitting inference while Contention is present, avoid "Throttle/Pause" — distinct from Preemption), Preemption (interrupting a running request for a higher-priority one, avoid "Kill/Cancel"), Job (a durable batch inference unit, SQLite-backed, survives restart), Queue (the ordered durable line of Jobs), Park/Parked request (short-lived in-memory holding for Batch requests during Yield), Fronting Proxy (entry point for Synchronous requests), Synchronous request (live, admitted-or-503, never saved), Embed lane (separate CPU-only lane fronting Infinity SigLIP, unrelated to this feature), Consumer (any service sending inference requests through the Broker).
